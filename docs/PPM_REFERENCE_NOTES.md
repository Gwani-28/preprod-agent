# PPM 레퍼런스 분석

분석 대상:

- `AICRON_0503_PPMBOOK.pdf`
- `CONVERSE_PPM_최종.pdf`
- `filmhwa_0601_PPMBOOK.pdf`

세 파일은 광고 PPM 성격이 강하지만, 영화와 뮤직비디오에도 옮겨 쓸 수 있는 공통 구조가 뚜렷합니다.

## 공통 구조

1. 표지
2. Staff List
3. Concept / Synopsis / Objective
4. Scenario / Continuity / Storyboard
5. Mood Board / Visual Reference
6. Model / Casting
7. Wardrobe / Hair & Make-up / Art
8. Location
9. Props / Equipment
10. Shooting Schedule / Time Table / Call Sheet

## AICRON 계열에서 가져올 점

- 페이지 수가 많고 실무 준비 항목이 촘촘합니다.
- 장면별 레퍼런스와 컷 흐름이 강합니다.
- 장소, 모델, 의상, 장비, 소품, 일정표가 따로 분리되어 있습니다.
- 앱에서는 `체크`, `문서`, `예산`, `PPM`을 연결해서 상세 PPM으로 확장할 때 좋은 기준입니다.

적용 방향:

- 콘티/continuity 섹션 보강
- 장비/소품 섹션 보강
- 촬영 운영표를 최종 PPM에 포함

## CONVERSE 계열에서 가져올 점

- 표지와 Staff List가 간결합니다.
- 브랜드 톤을 유지하면서도 synopsis, scenario, continuity가 명확합니다.
- 마지막에 촬영표가 한 장으로 정리되어 회의용 자료로 바로 기능합니다.

적용 방향:

- 최종 PPM을 너무 장황하게 만들지 않는 압축형 모드가 필요합니다.
- PPM Preview는 핵심 정보를 앞쪽에 모으고, 상세는 뒤쪽으로 보내는 구성이 좋습니다.

## filmhwa 계열에서 가져올 점

- 여백이 크고 무드보드 중심입니다.
- 색감, 빛, 공간, 스타일링 감각을 시각적으로 먼저 설득합니다.
- MV나 감성 중심 브랜드 필름에 잘 맞는 구성입니다.

적용 방향:

- 톤앤매너와 레퍼런스 섹션을 단순 텍스트가 아니라 이미지/컬러 팔레트까지 받을 수 있게 확장할 여지가 있습니다.
- 비주얼 보드를 별도 탭으로 두고 최종 PPM에 자동 삽입하면, filmhwa식 무드 중심 PPM에도 대응할 수 있습니다.
- 영화/MV에서는 `기획의도`보다 `무드`, `리듬`, `퍼포먼스`, `공간감`을 더 앞에 둘 수 있습니다.

## 범용 PPM 설계 원칙

광고, 영화, MV를 하나의 앱에서 다루려면 섹션 이름을 너무 한 장르에 고정하지 않는 것이 좋습니다.

- `작품명`보다 `프로젝트명`
- `로그라인`보다 `한 줄 소개`
- `시나리오`보다 `시나리오 / 콘티`
- `모델`보다 `캐스팅 / 스타일링`
- `미술`보다 `미술 / 의상 / 소품`
- `콜시트`보다 `촬영 운영표`

## 앱에 반영한 구조

현재 앱의 PPM 본문은 다음 순서를 기준으로 합니다.

1. 프로젝트 개요
2. Staff List
3. 기획의도
4. 연출 방향
5. 톤앤매너
6. 레퍼런스
7. 비주얼 보드
8. 시나리오 / 콘티
9. 제작 방향
10. 촬영 전략
11. 캐스팅 / 스타일링
12. 미술 / 의상
13. 로케이션 노트
14. 소품 / 장비
15. 촬영 운영표
16. 일일촬영 계획표
17. 예산 개요
18. 프리프로덕션 진행 현황
19. 미확정 / 위험 항목
20. 회의 안건
21. 회의록 색인
22. 리스크 메모

이 순서는 광고형 PPM의 실무성을 가져오면서도 영화/MV 프로젝트의 서사와 무드 설명을 수용하도록 설계했습니다.
