## [0.1.0] — 2026-06-13

First public release.

### Added

- Local-first pre-production web app (React + Vite + TypeScript + Tailwind).
- Tabs: Dashboard, Checklist, Budget, Crew, Shooting plan, Documents,
  Visual board, Missing check, PPM preview.
- PPM Book assembly with HTML / Markdown / PDF export.
- All data stored in the browser (`localStorage`) — no backend, works offline.
- macOS one-double-click launcher (`프리프로덕션 에이전트 실행.command`).
- Hosted live demo via GitHub Pages.
